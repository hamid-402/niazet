# تست E2E نقش‌ها و چرخه کامل خدمت

بخش API این آزمون با دستور زیر از پوشه `apps/api` اجرا می‌شود:

```powershell
npm.cmd run test:e2e:roles
```

Runner یک دیتابیس تصادفی با پیشوند `niazat_e2e_` می‌سازد، هر ۲۰ migration را از صفر deploy می‌کند، seed را اجرا می‌کند و یک API موقت روی پورت تصادفی بالا می‌آورد. دیتابیس تنظیم‌شده پروژه تغییر نمی‌کند.

پوشش آزمون:

- ورود و مسیر مجاز هر شش نقش Super Admin، Ops، Finance، Support، Executor و Customer؛
- مرزهای منفی بین نقش‌ها و پاسخ 401 برای کاربر ناشناس؛
- ثبت idempotent سفارش، ارسال، تریاژ، قیمت‌گذاری، قبول قیمت و پرداخت آزمایشی؛
- مشاهده Payment، Escrow و Invoice توسط Finance؛
- تخصیص، پذیرش مجری، تکمیل چک‌لیست، گزارش پیشرفت و آپلود فایل امن؛
- تحویل، ورود به QC، تأیید تمام آیتم‌ها و دانلود خروجی با Signed URL؛
- تأیید مشتری، بستن سفارش و آزادسازی Escrow؛
- ساخت تیکت، Claim، پاسخ قابل مشاهده مشتری و Resolve توسط Support؛
- دسترسی Super Admin به Audit Log.

در `finally`، API موقت متوقف، فایل خروجی همان اجرا با کلید UUID حذف و فقط دیتابیس تصادفی اعتبارسنجی‌شده پاک می‌شود.

این سند فعلاً بخش API را پوشش می‌دهد. بخش مرورگری Accessibility/Responsive/Keyboard/Visual جداگانه در Roadmap باقی می‌ماند و فقط با runtime مرورگر داخلی اجرا خواهد شد.
