# فایل‌های کانفیگ ریشه پروژه (Next.js) — نسخه تمیزشده

این یک فایل مرجع است، نه یک فایل قابل‌اجرا. هر بخش زیر مربوط به یک فایل جداگانه در ریشه پروژه است. محتوای هر بخش رو در فایلی با همون نام (که بالای هر بخش نوشته شده) کپی کنید.

> `package-lock.json` (۶۷۵۲ خط) توی این مرجع نیامده چون فایل auto-generated هست و دستی کپی کردنش معنی نداره — به‌جاش به‌صورت فایل جدا (`package-lock.json`) کنارش گذاشتم؛ کافیه بعد از کپی کردن `package.json`، این فایل رو هم کنارش بذارید و `npm ci` بزنید.
